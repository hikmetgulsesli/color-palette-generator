## Codebase Patterns

### Project Structure
- src/lib/ — pure utility modules (no React, no DOM)
- src/components/ — React components with co-located CSS and tests
- src/test/ — infrastructure/setup tests
- src/lib/*.test.ts — co-located unit tests for utilities
- src/components/*.test.tsx — co-located unit tests for components

### Component Patterns
- Components use CSS custom properties for dynamic values (e.g., --hover-bg)
- Props interface exported for external use
- Test IDs used for reliable test selection (data-testid)
- Icons from Lucide React with aria-hidden="true"
- Gradient overlays for text legibility on variable backgrounds

### Color Types
- RgbColor: { r: number, g: number, b: number } (0-255)
- HslColor: { h: number, s: number, l: number } (h: 0-360 deg, s/l: 0-100 %)
- Hex: 7-char lowercase string "#rrggbb"
- PaletteColor: { id: string, color: string, locked: boolean }
